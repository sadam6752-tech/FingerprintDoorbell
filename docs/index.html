🔒 FingerprintDoorbell Flasher

Install FingerprintDoorbell on your ESP32 right from the browser — no tools, no PlatformIO.

This flasher installs the firmware over USB using ESP Web Tools (Web Serial). Connect your ESP32 with a USB cable, click the button below, pick the serial port and follow the steps. A full erase + install is performed, so the device starts fresh.

Browser support: works only in Chrome, Edge or Opera (desktop). Firefox and Safari do not support Web Serial.

After flashing

  1. The ESP opens a WiFi access point FingerprintDoorbell — connect and enter your WiFi.
  2. Open the device web UI at its IP address and set an admin password.
  3. Install the ioBroker.fingerprint adapter. With this firmware (v0.9.1+) it configures the device automatically (server mode).

Updating later

Future updates can be installed over the air (no USB needed): open http://<device-ip>/update, choose the new firmware.bin from the Releases page and upload it.
